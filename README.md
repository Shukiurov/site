# Ali Shukiurov — Portfolio

## Структура проекта

```
ali-portfolio/
│
├── index.html              ← ГЛАВНЫЙ ФАЙЛ (открывать в браузере)
│
├── css/
│   ├── main.css            ← переменные цветов, шрифты, курсор, фон
│   ├── nav.css             ← навигация сверху + мобильное меню
│   ├── bento.css           ← главная страница: сетка + карточки + анимации
│   ├── pages.css           ← страницы разделов, детальный вид, футер
│   └── responsive.css      ← адаптивность (мобильные, планшеты)
│
├── js/
│   ├── cursor.js           ← кастомный курсор
│   ├── translations.js     ← ВСЕ ПЕРЕВОДЫ (EN / NL / RU) — редактируй здесь
│   ├── data.js             ← КОНТЕНТ РАЗДЕЛОВ (тексты, инструменты, фото) — редактируй здесь
│   └── app.js              ← логика: навигация, смена языка, анимации
│
├── pages/                  ← HTML-части каждой страницы (для удобства редактирования)
│   ├── nav.html            ← навигация
│   ├── home.html           ← главная (бенто)
│   ├── about.html          ← раздел "Обо мне"
│   ├── technical.html      ← технические навыки
│   ├── cars.html           ← авторемонт
│   ├── analytical.html     ← аналитика
│   ├── digital.html        ← digital / IT
│   ├── cases.html          ← реальный опыт
│   └── detail.html         ← детальный просмотр
│
├── images/                 ← СЮДА кладёшь свои фото
│   └── (добавь photo.jpg здесь)
│
└── README.md               ← этот файл

## Как добавить своё фото

1. Положи фото в папку images/ (например images/ali.jpg)
2. Открой index.html, найди:
   src="https://images.unsplash.com/..."
3. Замени на:
   src="images/ali.jpg"

## Как добавить фото к разделу (например, к авторемонту)

Открой js/data.js, найди нужный ключ и добавь пути:

  timing_belt: {
    ...
    photos: ['images/timing1.jpg', 'images/timing2.jpg']
  }

## Как изменить текст переводов

Открой js/translations.js — там три объекта: en, nl, ru.
Найди нужный ключ и поменяй текст.

## Как запустить

Просто открой index.html в браузере.

## Как разместить онлайн

Загрузи ВСЮ папку на хостинг (Netlify, GitHub Pages, Vercel).
Netlify: перетащи папку на netlify.com/drop — готово за 30 секунд.
